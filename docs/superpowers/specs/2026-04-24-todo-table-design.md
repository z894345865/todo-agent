# TODO 表格视图设计文档

> **Goal:** 将 TODO 列表从简单列表升级为带排序和筛选功能的表格视图。

## 1. 技术选型

- **`@tanstack/react-table`** — 处理表格渲染、排序、筛选逻辑
- 新增依赖：`npm install @tanstack/react-table`

## 2. 组件

### 2.1 TodoTable（新建）

主表格组件，包含：
- **筛选栏**（顶部）：优先级选择、标签选择、状态选择、逾期选择
- **表头**（可点击排序）
- **表格体**（数据行）

表格列定义：
| 列 | 字段 | 宽度 | 可排序 |
|----|------|------|--------|
| 状态 | checkbox | 48px | 否 |
| 名称 | text | flex | 是 |
| 优先级 | priority | 80px | 是 |
| 标签 | tags | 160px | 否 |
| 截止日期 | dueDate | 100px | 是 |
| 描述 | description | flex | 否 |

### 2.2 TodoEditModal（新建）

编辑弹窗，包含所有字段的编辑表单：
- 名称（文本输入）
- 优先级（PrioritySelector）
- 截止日期（date input）
- 标签（TagSelector）
- 描述（文本输入）
- 状态（完成/未完成切换）
- 删除按钮

点击表格行打开弹窗，保存后关闭。

## 3. 筛选项

四个筛选维度，全部聚合在表格顶部：

| 筛选项 | 选项 |
|--------|------|
| 优先级 | 全部 / 高 / 中 / 低 |
| 标签 | 全部 / 各标签名（动态从 store.tags 获取） |
| 状态 | 全部 / 进行中 / 已完成 |
| 逾期 | 全部 / 已逾期 / 未逾期 |

筛选逻辑：AND 组合（所有筛选项同时生效）。

## 4. 排序

- 可排序字段：名称、优先级、截止日期、创建时间
- 点击表头切换排序状态：无序 → 升序 → 降序
- 优先级排序规则：高 > 中 > 低（数值映射）
- 默认排序：按创建时间降序（最新在上）

## 5. 表格样式

- **斑马纹行**：奇偶行背景色不同
- **优先级列**：彩色圆点（高=#EF4444 / 中=#EAB308 / 低=#22C55E）
- **标签列**：TagBadge 组件，支持多标签
- **截止日期**：逾期且未完成的显示红色 + ⚠ 前缀
- **描述列**：超过宽度截断，hover 显示完整内容（title 属性）

## 6. 文件变更

**新建：**
- `src/components/TodoTable.tsx` — 表格主组件
- `src/components/TodoEditModal.tsx` — 编辑弹窗

**修改：**
- `src/App.tsx` — 用 `<TodoTable />` 替换 `<TodoList />` 和 `<TodoItem />`
- `package.json` — 新增 `@tanstack/react-table` 依赖

**保留（不删除）：**
- `TodoList.tsx`、`TodoItem.tsx` — 保留但不再被 App 使用

## 7. 迁移策略

- 直接替换，筛选项默认"全部"，排序默认创建时间降序
- 无数据迁移需求
